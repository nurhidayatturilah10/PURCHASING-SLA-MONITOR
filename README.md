# PURCHASING-SLA-MONITOR
Aplikasi atau modul perangkat lunak yang dirancang untuk melacak, mengukur, dan memastikan seluruh proses pengadaan barang/jasa baik dari sisi tim internal maupun supplier/vendor eksternal berjalan sesuai batas waktu dan standar layanan (Service Level Agreement / SLA) yang telah disepakati. Aplikasi ini berfungsi sebagai sistem kendali.
